**Coleta:** 24/11/2026, aproximadamente às 23:35 UTC (20:35 em America/Sao_Paulo).  
**Fonte:** APIs de leitura do GitHub para regras efetivas por branch e detalhes dos rulesets do repositório ifpebj-ti/lab-solos. As consultas responderam em sessão autenticada do GitHub CLI.  
**Abrangência:** regras aplicadas a refs/heads/develop e refs/heads/main; lista completa de cinco rulesets retornada com per_page=100. Quatro estavam ativos e um estava desabilitado. Não foram alteradas regras.

- develop: exige estritamente Frontend quality, Backend quality, Workflow contracts, Scan frontend on linux/amd64, Scan frontend on linux/arm64, Scan backend on linux/amd64, Scan backend on linux/arm64, Code quality baseline e Quality gate; também bloqueia exclusão e avanço não fast-forward.
- code-quality-develop: exige estritamente CodeQL (csharp) e CodeQL (javascript-typescript). A regra de code scanning informa errors_and_warnings para alerts_threshold e none para security_alerts_threshold.

## main

Fontes aplicáveis: rulesets main e code-quality-main, ambos ativos.

- main: bloqueia exclusão e avanço não fast-forward; exige pull request, permite merge, squash e rebase, configura zero aprovações obrigatórias, não exige aprovação de CODEOWNERS nem resolução de conversas, e exige aprovação adicional para alterações sem atribuição.
- code-quality-main: aplica o limiar warnings para qualidade de código.

## Proteção clássica e limites

As consultas às regras efetivas por branch foram bem-sucedidas. As consultas GET /repos/ifpebj-ti/lab-solos/branches/develop/protection e .../branches/main/protection responderam HTTP 404 com “Branch not protected”. Portanto, não há proteção clássica devolvida por essas rotas; as regras acima vêm dos rulesets e da API de regras efetivas.

A evidência descreve a configuração observada no instante da coleta. Jobs de CI que executam em um PR não são tratados como obrigatórios, a menos que apareçam na fonte efetiva de regras. Nenhum ID interno de ruleset, identidade de usuário ou credencial foi registrado.
