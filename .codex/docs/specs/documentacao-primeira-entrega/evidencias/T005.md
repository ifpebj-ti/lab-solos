Os comandos usam Bash declarado, com dump pg_dump --format=custom copiado como arquivo e restaurado por pg_restore, sem redirecionamento textual. A checagem estrutural, os dois Compose e git diff --check foram repetidos depois do refactor, todos com sucesso.
