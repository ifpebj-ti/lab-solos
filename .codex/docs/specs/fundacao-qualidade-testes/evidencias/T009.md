# Evidência T009 — gate contra uma base confiável

- Data: 2026-09-15
- Tarefa: T009
- Resultado: concluída
- Issue: #237 (aberta; Project 41 em `In Progress`)

## RED

A delegação inicial confirmou a lacuna: `quality_baseline.py` implementava
somente `collect` e `render`, sem `compare_findings`, `check_quality` ou o
subcomando `check`. Foram adicionados sete testes RED para multiplicidade,
base confiável, bootstrap, coleta incompleta, alto histórico, backlog,
falso-positivo e fingerprint incompatível; os 18 testes anteriores passaram e
os sete novos falharam pela ausência das funções.

## GREEN

O gate foi implementado com os seguintes contratos:

- `compare_findings` compara contagens por fingerprint, preserva duplicatas e
  rejeita ocorrência nova mesmo quando a contagem total não aumenta.
- `check_quality` resolve e lê `baseline.json` e `policy.json` com `git show`
  na revisão indicada por `--base-ref`; a cópia modificável do working tree
  não substitui a base confiável.
- Baseline ausente dispara bootstrap em worktree descartável da revisão base,
  usando a mesma coleta; falhas de referência, política, fingerprint ou
  produtor retornam código 2.
- Código 0 exige coleta completa, política/fingerprint compatíveis e nenhuma
  violação; código 1 identifica achados novos ou falso-positivo sem
  correspondência; código 2 identifica falha operacional/configuração.
- Altos históricos são recusados. Médios/baixos históricos exigem
  `backlogId` e `owner` individualmente.

## REFACTOR e validação

- `python -B -m unittest discover -s .github/scripts/tests -p test_quality_baseline.py -v`:
  **25 testes aprovados**.
- Os testes exercitam repositórios Git temporários e não fazem fetch,
  sobrescrita de baseline, alteração de `origin/develop` ou acesso à rede.
- O CLI recebeu `check --current <arquivo> --base-ref <revisão>` e propaga os
  códigos do gate.
- A implementação mantém `collect`/`render` e os contratos existentes; não
  altera baseline nem fecha pendências automaticamente.
- Não houve commit, push, merge, PR ou alteração de `tasks.md` nesta tarefa.
