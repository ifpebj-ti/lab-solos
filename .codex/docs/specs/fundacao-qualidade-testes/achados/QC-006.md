# QC-006 — avisos de recurso e tamanho do pacote

## Reprodução objetiva

`npm run build` no frontend terminou com código 0 e transformou 3.835
módulos. O Vite registrou três avisos observáveis:

1. `index.html` referencia `/env.js` sem `type="module"`;
2. `public/images/laboratory.png` é referenciado por uma URL que não é
   resolvida durante o build;
3. o chunk JavaScript principal tem aproximadamente 4,01 MB bruto e excede
   o limite informativo de 500 kB.

O runtime Docker gera `/env.js` no entrypoint a partir de
`.env.template.js`, e `laboratory.png` existe em `public/images`; portanto os
dois primeiros avisos não provaram indisponibilidade em runtime nesta tarefa.
O chunk grande é um risco mensurável de carregamento, mas o build não falha e
não há medição de desempenho de usuário que justifique severidade alta.

## Decisão T027

QC-006 permanece uma pendência baixa e rastreável. Não foi incluído como alto
nem usado para adulterar o baseline. A correção futura deve medir carregamento
em um ambiente representativo e decidir entre corrigir a referência, ajustar o
pipeline ou dividir o bundle; nenhuma dessas mudanças é necessária para
concluir a consolidação de T027.
