# Lista local de senhas comuns

- Origem: compilação própria do projeto LabOn, criada para bloquear exemplos comuns e previsíveis sem consulta externa.
- Versão: 1.0.0 (2026-08-30).
- Licença: CC0-1.0; o projeto renuncia, na medida permitida por lei, a direitos sobre esta compilação.
- Formato: UTF-8, uma senha por linha; linhas iniciadas por `#` são comentários.

O arquivo é incorporado ao assembly. A aplicação falha durante o registro dos serviços quando o recurso está ausente ou vazio. A comparação usa FormKC e caixa indiferente somente para consultar a lista; o valor original não é transformado, retornado ou registrado.
